# Photography

Source: [Lab for Eco-hydrodynamic Interactions gallery](https://www.garylei.com/gallery), accessed 16 September 2026.

The gallery credits **Gary Lei, Zichen Xu, and Yushu Xie** collectively. It does not identify an individual photographer for each image. These images are used at Gary Lei's request for this CE2134 hub; no general redistribution licence is asserted.

- `mangroves.jpg`: mangrove foliage and exposed roots (gallery first row, right).
- `vegetation-study.jpg`: submerged vegetation models in a laboratory study (gallery second row, left). This is a real photograph of model vegetation, not a natural seagrass meadow.
- `water-seedlings.jpg`: rippling water around potted mangrove seedlings (gallery first row, left).

Photographs are resized to a maximum width of 720 pixels and JPEG-compressed for web delivery, preserving their full aspect ratios. The masthead uses CSS cropping and a contrast overlay. No AI-generated imagery is used.
